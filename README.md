# Cloud Function Template repository
Allow easy workspace setup while developing Google Cloud Functions.

Key features
- [TypeScript 3.7][1] (compiles with tsc)
- [ESLint][2] [configured for TypeScript][3] with recommended settings
- [Jest][4] for unit tests
- [Sentry][5]-ready

[1]: https://www.typescriptlang.org/docs/handbook/release-notes/typescript-3-7.html
[2]: https://eslint.org
[3]: https://typescript-eslint.io
[4]: https://jestjs.io
[5]: https://sentry.io
